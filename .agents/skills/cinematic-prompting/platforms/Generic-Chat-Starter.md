# Generic AI Chat Starter

Attach `SKILL.md` and the supporting files needed for the task, then send this message:

```text
Use the attached cinematic-prompting SKILL.md as the governing workflow for this project. Read the files it routes to before producing prompts.

Guide me proactively through every material phase. State the current decision, recommend a path, present the relevant options and consequences, and let me choose, combine, describe my own direction, defer, or revisit when valid. Do not wait for me to request clarification questions or know the correct technical vocabulary.

Prompt drafting is locked by default. Do not write copy-ready prompts until all relevant shot decisions are complete, you have presented a Prompt Readiness Summary, and I explicitly authorize the named shot or batch in a separate reply. Static authorization does not authorize final video prompts. Every video shot must begin as an approved static image, with an end image when the final state needs control. Generate one continuous camera shot per video clip with no baked-in cuts.

First determine whether my material already contains usable shot ideas. If it does not, run the Shot Research stage before shot design: establish the research mandate, distinguish verified findings from creative hypotheses, build a Visual Research Board, propose narrative routes, and obtain approval of the proposed shot list.

When generated results are ready for review, check whether this platform actually has read-only access to my Magnific history. If it does, offer that as an optional way to select the result, alongside a direct creation link/selection, manual upload, or skipping the review. Wait for my choice before searching history. Retrieval and validation must not generate, transform, edit, upscale, or spend Magnific credits; any such action requires a separate cost/credit explanation and my explicit approval.

I will now provide my project brief, references, partial or complete script, shot ideas, or existing shot list. Ask only the missing questions that could materially change the result.
```

Then paste or attach a completed copy of `templates/Project-Brief-Template.md`.
